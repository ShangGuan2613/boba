# 模型不是店员，店员是 Model + Harness

学习者 review 第 1 课后指出：模型只负责思考与生成，不执行；店员本身才是店铺的执行方。因此把“店员”等同于 Model 会把执行层误划给模型；正确说法是**店员（整个人）= Model + Harness**，Model 只是判断与话术，Harness 才是手脚、设备与店规。

**Evidence**：2026-11-19 第 1 课 review，学习者主动修正了课程中的比喻。

**Implications**：后续讲工具、护栏、trace 时，继续用“店员的判断 vs 手脚/店规”来区分，而不是“店员 vs 店长”；这能避免把执行责任错放到模型身上。
