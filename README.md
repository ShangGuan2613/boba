# Boba · 从奶茶店学 Agent Harness

这是 `/teach` 教学工作区，不是产品仓库。

目标：用“开奶茶店”这个具体场景，从零搭出可运行的 Agent 与 Harness，并理解每个设计背后的失败模式。

## 怎么上课

1. 打开 `lessons/` 里的下一课（自包含 HTML，直接双击或 `open`）。
2. 读完，做课末的检索练习——先凭记忆答，再点提交。
3. 把你的判断、反对意见、追问发回给我。下一课由你的追问决定。
4. 每课结束，进程用 STAR、经验用 STD-1000 记到 Notion。

## 课程结构

固定四段：**问题 → 设计 → 代码 → 复盘**。

- 问题必须来自奶茶店：顾客、订单、库存、出杯、排队。
- 设计只解决当前问题，不提前抽象。
- 代码可运行、可验证；跑通再扩展。
- 复盘说清楚：这一课故意没做什么。
