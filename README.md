# Boba（波波茶铺）· 从零手写 Agent Harness

这个仓库现在不是成品，而是**学习现场**：从空文件开始，一个概念一个概念地长出 Agent 与 Harness。奶茶店是例子，不是限制。

> 之前的完整 MVP 已归档在 tag `v0.1-mvp` 和分支 `mvp-v0.1`，随时可以对照；学习过程中尽量先不看。

## 学习约定

- 你写核心代码；教练只给概念、边界、最小提示和 review。
- 一次只推进一个概念；跑通、讲清楚，再下一个。
- 每个概念都有可运行的验证点，不引入没有必要的框架或依赖。
- 复杂度由需求逼出来，不从“最佳实践”抄结构。
